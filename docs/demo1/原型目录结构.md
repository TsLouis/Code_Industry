## 2. 核心模块说明

### 2.1 适配器模块 (adapters/)
- 实现最基础的LLM调用接口
- 支持OpenAI和Claude两个主要供应商
- 包含基础的重试机制

### 2.2 Agent模块 (src/agents/)
- 实现三个基础Agent：
  1. 协调者：负责任务分配和进度管理
  2. 产品经理：需求分析和任务拆解
  3. 开发者：代码实现和问题解决

### 2.3 通信模块 (src/core/comms/)
基础消息格式：
```python
{
    "id": "msg_uuid",
    "type": "task",  # task/response/status
    "sender": "agent_id",
    "receiver": "agent_id",
    "content": {},
    "timestamp": "iso8601"
}
```

### 2.4 状态管理 (src/core/state/)
- 维护基本的对话上下文
- 管理任务状态
- 追踪Agent状态

## 3. 数据目录说明

### 3.1 outputs/
- requirements/ - 存放产品经理Agent生成的需求文档
- design/ - 存放架构师Agent生成的设计文档
- code/ - 存放开发者Agent生成的代码文件
- tests/ - 存放测试Agent生成的测试文档

### 3.2 history/
- conversations/ - 按日期和会话ID组织的对话记录
  ```
  conversations/
  ├── 2024-03-20/
  │   ├── session_001/
  │   │   ├── messages.json    # 对话消息
  │   │   └── metadata.json    # 会话元数据
  │   └── session_002/
  └── 2024-03-21/
  ```

### 3.3 logs/
- system/ - 系统运行日志
- agents/ - 各Agent的运行日志
  ```
  agents/
  ├── coordinator/
  ├── product_manager/
  └── developer/
  ```

## 4. 文档目录说明

### 4.1 docs/
- architecture/ - 系统架构设计文档
- api/ - API接口文档
- guides/ - 使用指南和开发文档

## 5. 配置文件说明

### 5.1 agents.yaml
```yaml
agents:
  coordinator:
    type: coordinator
    model: gpt-4
  product_manager:
    type: product
    model: gpt-4
  developer:
    type: developer
    model: claude-3
```

### 5.2 system.yaml
```yaml
system:
  log_level: INFO
  retry_attempts: 3
  timeout: 30

providers:
  openai:
    api_key: ${OPENAI_API_KEY}
  anthropic:
    api_key: ${ANTHROPIC_API_KEY}
```
