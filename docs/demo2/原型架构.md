## 2. 系统架构

### 2.1 核心模块
1. Agent模块
```
/agents
├── base/              # 基础类
│   ├── agent.py      # Agent基类
│   └── types.py      # 类型定义
├── coordinator/       # 协调者
├── product_manager/   # 产品经理
└── developer/        # 开发者
```

2. 通信模块
```
/core
├── messaging/         # 消息处理
│   ├── broker.py     # 消息代理
│   └── types.py      # 消息类型
└── state/            # 状态管理
    └── context.py    # 上下文
```

3. 适配器模块
```
/adapters
├── openai/           # OpenAI适配器
│   ├── client.py     # API客户端
│   └── config.py     # 配置
└── base/             # 基础接口
```

### 2.2 数据流
1. 消息流转
   - Agent发送消息
   - 消息代理转发
   - 目标Agent处理
   - 返回响应

2. 状态管理
   - 任务状态跟踪
   - 会话状态维护
   - 上下文管理
